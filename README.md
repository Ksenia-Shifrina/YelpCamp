# YelpCamp

This project, developed during a Udemy bootcamp, is a deployed website that allows users to tag and review campsites on a map. Users can view descriptions of campsites and, upon logging in, can comment, rate, and manage their own campsite entries. If a user owns a campsite, they have the ability to edit or delete it.

## Key Features

- Interactive map for tagging campsites
- User authentication and authorization
- Commenting and rating system for campsites
- Ability to add, edit, and delete campsites

## Learning Highlights

- **DOM Manipulation**: Learned to dynamically change the content of the page and interact with the DOM, providing a seamless user experience.
- **Backend Development**: Introduced to **NodeJS** and **ExpressJS** for building the server and handling routing, helping me understand the basics of server-side development.
- **Asynchronous JavaScript**: Worked with **Promises** and **async/await** to manage asynchronous operations, such as fetching and posting data to the server.
- **CRUD Operations**: Implemented **Create, Read, Update, Delete (CRUD)** functionality for campsite reviews, using **MongoDB** and **Mongoose** to manage data and design schemas for user and campsite information.
- **Authentication and Security**: Gained practical experience in building authentication from scratch, handling **cookies** and **sessions**, and implementing **authorization** to control access.
- **Third-Party Integrations**: Integrated external services for **maps** and **geocoding** to display campsite locations, and **image upload and storage** to allow users to upload photos.
- **Cloud Deployment**: Deployed the application to a cloud platform and managed a **cloud database**, ensuring the app was functional in a production environment.
- **Full-Stack Development**: Learned key skills in **full-stack development**, including backend setup, database management, user authentication, and security, which laid the foundation for more complex projects.
